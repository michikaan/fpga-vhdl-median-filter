# Generated test vectors

The MATLAB script generates the text files used by the file-based VHDL testbench.

- `noisy_pixels_padded_130.txt`: 130 x 130 padded noisy input image, one decimal pixel value per line, row-major order (16900 values).
- `reference_pixels_128.txt`: MATLAB median-filter reference, one decimal pixel value per line, row-major order (16384 values).
- `vhdl_output_128.txt`: generated by the VHDL TEXTIO testbench (16384 values).

These files are generated artifacts and do not need to be committed. Copy `noisy_pixels_padded_130.txt` into the simulator working directory, or adjust `C_INPUT_FILE` in `tb/tb_median_filter_file.vhd`.
